📖 How to Export Your Watchlist Data

Follow these step-by-step instructions to export your complete watch history, ratings, and episode logs from each platform, then drop the resulting file into this app!

1. Trakt.tv (Full Export ZIP)
  1. Log in to Trakt.tv.
  2. Go to Settings → Advanced tab.
  3. Scroll down to Export Data and click Export.
  4. Download the generated .zip file (contains watched_shows.csv, watched_movies.csv, ratings_shows.csv, etc.).
  5. Drop the entire .zip file directly into our drop zone!
2. Simkl (CSV / Auto PKCE Sync)
  1. Option A (Auto Sync): Click ⚡ Connect Simkl (PKCE) above for 1-click automatic import/export!
  2. Option B (Manual CSV): Log in to Simkl Backup Settings.
  3. Click Export to CSV to download your SimklBackup.csv file.
  4. Drop the .csv file into our drop zone.
3. MyAnimeList (MAL XML Export)
  1. Log in to MyAnimeList Panel Export.
  2. Click Export Anime List.
  3. Download the animelist.xml.gz or animelist.xml file.
  4. Drop the .xml or .gz/.zip file into our drop zone.
4. Nuvio TV
  1. Use ⚡ Sync Watched to Nuvio API for direct API watched history import!
  2. Or drop any previously exported nuvio_watched_sync.json file.
